# Movie Library - Личная кинотека

**Автор:** Шарко Никита

## 📝 Описание

Movie Library - это графическое приложение для ведения личной коллекции фильмов. Позволяет добавлять, просматривать, редактировать и удалять фильмы, а также фильтровать их по жанру и году выпуска. Все данные сохраняются в JSON-файл.

## ✨ Основные возможности

- ➕ Добавление фильмов с информацией (название, жанр, год, рейтинг)
- 📋 Просмотр всех фильмов в удобной таблице
- 🔍 Фильтрация по жанру
- 📅 Фильтрация по диапазону годов
- ✏️ Редактирование информации о фильмах
- 🗑️ Удаление фильмов из библиотеки
- 📊 Статистика (количество фильмов, средний рейтинг)
- 💾 Автоматическое сохранение в JSON-файл
- ✅ Полная валидация вводимых данных
